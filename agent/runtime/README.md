# Catnip Forge Rig Agent

Rust/Rig supplies the existing Worker's inference loop. Electron Main owns model selection, credentials, tool validation and execution; the Worker remains the only task queue. This is an Anthropic Messages adapter with streaming responses, not a second task system.

Build from the repository root with `npm --prefix electron run build:agent`. Rust 1.95 or later and the platform's native C++ linker are required on the development machine. `rig-core` is pinned to 0.44.0 and builds use `Cargo.lock`. The build copies the release executable to `agent/bin/catnip-agent.exe` on Windows. Customers run the packaged binary without Rust or Claude Code.

Run `cargo test --locked --manifest-path agent/runtime/Cargo.toml`, `npm --prefix electron run verify:rig-protocol`, `npm --prefix electron run verify:agent-tools` and `npm --prefix electron run verify:rig-host` after `build:main`. All three fixtures run offline with temporary project/session data and invalid fixture credentials. The protocol test launches the real binary; the host test also launches the real Runtime MCP server.

The process reads bounded JSONL frames from stdin and writes JSONL events to stdout. The first frame is `init`, containing the frozen provider/model snapshot, system prompt, tool definitions and context budget. Its credential exists only in Main and the process's memory. `ANTHROPIC_API_KEY` maps to `x-api-key`; `ANTHROPIC_AUTH_TOKEN` maps to `Authorization: Bearer`. No credential or MCP config is passed in argv.

Each subsequent `user` frame starts one turn. The model's tool call emits a Worker-compatible `assistant/tool_use` observation plus a `tool_request`. Main validates its schema, profile and project before returning a `tool_response` with `content` and `isError`. The runtime then records the result and resumes inference. A `result` event completes the turn; a failed turn is terminal. Stop kills the owned Rig process and MCP process tree. There is no arbitrary shell, erase-flash or subagent tool.

History is appended beneath the selected project's `.catnip/agent/rig/<conversation-hash>/history.jsonl`. Old Worker history is imported once when that archive is empty. Context compaction adds a summary and boundary, retaining the full source archive and complete tool exchanges. The summary carries goals, constraints, progress, decisions, evidence, next steps and file paths; it grants no new permission. On restart an unfinished call receives `INTERRUPTED_TOOL_OUTCOME_UNKNOWN`; it is never replayed.

Context budgets are frozen with each queued provider snapshot. DeepSeek defaults to 1,000,000 tokens; other providers default to 131,072. The model page can set capacity and output limits (default 32,768). Reserve includes output plus safety headroom (at least 8% of capacity); recent history keeps up to 24,000 tokens. Conservative estimates count system rules, Tool schemas, complete history projection and protected board text. Safe usage counters and compaction phases drive the Chat remaining-capacity ring; provider counters are shown separately. Near-limit history compaction preserves raw append-only records and complete Tool pairs. Provider overflow triggers one forced attempt. Oversized input or failed compaction returns an explicit error without deleting history. A configured 1M budget and a successful small request do not prove provider acceptance of a full 1M request.

A stream can wait 180 seconds for its first event and 180 seconds between subsequent events; text, reasoning and Tool argument activity reset that idle wait. The overall response ceiling is 15 minutes. Timeout diagnostics contain only event counts, byte counts and elapsed time, never raw reasoning or provider payloads. Partial Tool calls are never executed. Main detects a dead Runtime MCP transport and reports unknown outcome for an interrupted request; only a later explicit Tool call reconnects, without replaying the lost operation.

Tools live in `electron/src/main/agent-tools/`. Add a separate `AgentTool` definition with an input schema, allowed profiles and execution function; the registry bounds results and rejects known credentials in ordinary tool arguments. Runtime MCP exposure is curated. Analysis allows only `Skill` and `StructuredOutput`; planning allows only `StructuredOutput`. Existing Explore confirmation remains the gate into the normal engineering profile.

Runtime screenshots are saved under the current project's controlled `.catnip` state and return an image identifier and path. `browser_analyzeScreenshot` uses the existing Main-only Qwen adapter and returns visual evidence and uncertainty. Capturing a screenshot alone proves no visual outcome. Missing Qwen configuration returns an explicit error; fixtures do not make paid requests. Runtime recordings/workflows/storage use the current project's `.catnip/agent/runtime-tools/` namespace.

BoardPacks include builtin reference data beneath `agent/board-packs/` and user-selected project reference ZIPs beneath the Main-managed `.catnip/board-info/`. Project creation optionally imports and validates a source-free board kit. When bound, `BoardPack({source:"project"})` returns its summary; document reads with the same source explicitly load the manifest and declared text, with bounded line paging. Reference files cannot be modified by ordinary Agent Tools. Task context includes the project package reference and loading policy. Main revalidates all declared UTF-8 documents and supplies their full original text as an independent, bounded protected reference segment in every default-profile request; history compaction cannot remove it. The segment counts toward the context budget and fails explicitly above 512 KiB rather than trimming facts. Explore receives no protected segment. Without a project package, enumerate builtin packs and read the matching manifest and declared text such as `HARDWARE.md`. The generic ESP32-S3 pack has no display model or pins; selecting it does not authorize invented wiring. The schematic PDF remains raw evidence, not proof of model understanding. Build, Flash, Serial and actual screen behavior each require their own evidence.
